
# Lab 8: PyTorch – Building and Training Neural Networks

In this lab, I completed six exercises using PyTorch:

### 1. Autograd and Gradient Calculation
- Used PyTorch autograd to calculate gradients and compared them with numerical gradients to verify the results.

### 2. Building and Training a Neural Network
- Built a neural network using nn.Module, Linear layers, ReLU, and optional Dropout.
- Implemented a training loop using Cross-Entropy Loss and the Adam optimizer.

### 3. DataLoader, Evaluation, and Regularization
- Used DataLoader for batching and shuffling, and evaluated the model using loss and accuracy.
- Added support for Dropout and Weight Decay, and created a reusable training function to track training and validation results.
